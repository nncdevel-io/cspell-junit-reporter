## Project Overview

**cspell-junit-reporter** is a CSpell reporter plugin that outputs spell check results in JUnit XML format.

- **Type**: TypeScript npm package
- **Purpose**: Convert CSpell spell check issues into JUnit XML reports for CI/CD integration
- **Main Export**: CSpell reporter module that implements the CSpell reporter interface

## Architecture & Design Patterns

### Reporter Interface

The reporter implements two main callbacks:

1. `issue(issue: Issue)` - Called for each spell check issue (accumulates issues)
2. `result()` - Called at end to generate JUnit XML output

### Issue Grouping

Issues are grouped by the forbidden word (`text` field) and each group becomes a JUnit test suite.

### Output Format

- Each forbidden word = one test suite
- Each occurrence = one test case (marked as failure)
- Test case names include file path and line number
- File references use relative paths with `#L{line}` anchors

## Common Issues & Solutions

### Build Failures

- Ensure Node 18+ is installed
- Run `npm install` to ensure dependencies are current
- Check `tsconfig.json` for configuration issues

### Test Failures

- Clear coverage directory: `rm -rf coverage`
- Reinstall dependencies: `rm -rf node_modules && npm install`
- Check Jest configuration in `jest.config.js`

### Publishing Issues

- Verify authentication: `npm whoami`
- Check package scope is `@nncdevel-io`
- Ensure `publishConfig.access` is set to `public`
